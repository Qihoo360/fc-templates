# 应用介绍

Presenton是开源的 AI PPT 生成工具，用来把自然语言提示词、文档、数据直接生成可编辑 PPTX/PDF，对标 Gamma、Canva、Beautiful AI、Decktopus、Presentations AI。

本案例是将Presenton，快速创建并部署到函数计算 FC 。

* [官方网站](https://presenton.ai/)
