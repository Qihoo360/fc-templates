# Open-WebUI

Open WebUI是一个可扩展、功能丰富且用户友好的自托管AI平台，旨在完全离线操作。它支持 Ollama 和 OpenAI兼容API 等各种 LLM 运行器，内置RAG推理引擎，使其成为强大的 AI 部署解决方案。

## 使用流程

### 📖 文档

- [Open-WebUI 使用手册](https://docs.openwebui.com/)

### 👋 特点

- **自托管与离线运行**：可完全本地部署，支持 Docker、Kubernetes 等，确保数据隐私和安全性，无需依赖云端。
- **多模型支持**：兼容多种 LLM 运行器（如 Ollama、OpenAI API），并支持与 LMStudio、GroqCloud 等集成，提供灵活的模型选择。
- **用户友好界面**：类似 ChatGPT 的直观设计，支持响应式布局、PWA 功能和主题定制，适配多种设备。
- **高级交互功能**：内置 RAG 引擎、语音输入、网页浏览、图像生成和多模态支持，提升信息检索和交互体验。
- **高度可定制**：通过管道和插件框架扩展功能，支持企业级定制（如品牌化、主题），满足个性化需求。
