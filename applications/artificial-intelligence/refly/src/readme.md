# 应用介绍

本案例展示了如何快速创建并将 **Refly** 部署到函数计算 FC。

**Refly** 是一款开源的大语言模型（LLM）应用开发平台，旨在帮助用户构建更高效、更可扩展的 AI 知识管理与应用系统。它融合了“智能知识工作流（AI Knowledge Workflow）”与 LLMOps 的理念，使开发者、研究人员与企业用户能够以最小成本，快速实现从知识整理到智能应用落地的全链路体验。

Refly 内置了开发 AI 应用所需的关键能力，包括多模型支持、灵活的提示词（Prompt）编排、先进的知识检索（RAG）与图谱引擎、可扩展的 Agent 框架，以及完善的工作流自动化工具。同时，Refly 提供直观的 Web 界面与 API 接口，帮助用户减少重复开发工作量，加快知识智能化转型的进程。

通过 Serverless 平台，您只需几步即可运行 Refly，并享受 Serverless 架构带来的高弹性与高可用性。

# 特色

**1、多模态知识检索与增强问答**
Refly 不仅支持文本知识库检索，还支持 **文档、图片等多模态数据** 的解析与索引。在问答时，可以结合文本与图像内容，提供更丰富、更精确的知识增强答案。

**2、智能知识图谱构建**
内置语义解析与关系抽取引擎，自动构建 **知识图谱**，帮助用户直观理解知识之间的关联，提升复杂问题的回答能力。

**3、智能上下文增强与问题优化**
Refly 支持上下文语义追踪与问题优化，能够将用户的不完整输入转化为更精确的检索与调用指令，显著提升答案相关性与一致性。

**4、可编排的智能 Agent 框架**
支持自定义 Agent 角色与行为，通过工作流编排可以轻松实现多步任务自动化，例如知识检索 + 总结 + 翻译的组合式 Agent。

**5、可视化工作流与低代码配置**
Refly 提供 **低代码工作流编辑器**，支持用户通过拖拽、配置的方式快速搭建 AI 应用，无需繁琐编程。

**6、开放与灵活的模型接入**
Refly 已支持全球 20+ 主流模型（OpenAI、Claude、Llama、Mistral、Qwen 等），只需配置 API Key 即可接入。

**7、丰富的数据导入与处理能力**
支持 Word、Excel、PPT、PDF、Markdown、OFD 等多种格式文档导入，并提供自动分段、QA 拆分、嵌入向量化等处理能力。

**8、企业级安全与权限管理**
提供多层安全机制：

* 本地化存储，确保数据自主可控
* 传输加密与访问权限控制
* 审计日志与操作追踪
  满足企业对数据安全与合规性的要求。

**9、开放生态与插件扩展**
Refly 拥有插件化架构，用户可以快速扩展自定义工具、外部 API 调用与第三方系统对接，构建更灵活的 AI 知识应用生态。
