# 应用介绍

本案例是将 unstructured ，快速创建并部署到函数计算 FC 。

该unstructured库提供了用于摄取和预处理图像和文本文档（例如 PDF、HTML、Word 文档等）的开源组件。 unstructured的用例围绕着简化和优化LLMs的数据处理工作流程。 unstructured模块化功能和连接器形成一个内聚系统，简化了数据摄取和预处理，使其能够适应不同的平台，并有效地将非结构化数据转换为结构化输出。

通过 Serverless 开发平台，您只需要几步，就可以体验 unstructured 框架，并享受 Serverless 架构带来的降本提效的技术红利
