# 应用介绍

本案例是将 LandPPT，快速创建并部署到函数计算 FC 。

LandPPT 是一个基于大语言模型（LLM）的智能演示文稿生成平台，能够自动将文档内容转换为专业的PPT演示文稿。平台集成了多种AI模型、智能图像处理、深度研究功能和丰富的模板系统，让用户能够轻松创建高质量的演示文稿

* [代码](https://github.com/Qihoo360/fc-templates/tree/feature/main/applications/artificial-intelligence/landppt/src)

* [官方网站](https://landppt-doc.52yyds.top/)
