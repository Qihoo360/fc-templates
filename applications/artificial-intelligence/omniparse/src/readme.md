# 应用介绍

本案例是将 omniparse ，快速创建并部署到函数计算 FC 。

OmniParse 是一个平台，可将任何非结构化数据提取并解析为针对 GenAI ( LLM ) 应用程序优化的结构化、可操作的数据。无论您正在处理文档、表格、图像、视频、音频文件还是网页，OmniParse 都会使您的数据变得干净、结构化，并为 RAG、微调等 AI 应用程序做好准备

通过 Serverless 开发平台，您只需要几步，就可以体验 omniparse 框架，并享受 Serverless 架构带来的降本提效的技术红利。

* [官方网站](https://omniparse.cognitivelab.in/)
