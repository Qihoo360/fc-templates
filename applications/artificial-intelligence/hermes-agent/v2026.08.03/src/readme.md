# 应用介绍

本案例是将 Hermes-Agent ，快速创建并部署到函数计算 FC 。

**Hermes Agent** 是 Nous Research在 2026 年 2 月发布的**开源、自托管、可自我进化的 Autonomous AI 智能体**，MIT 协议，无遥测，数据全部留在你自己服务器上。

**核心亮点**：**闭环自学习循环**—— 解决任务之后自动沉淀、生成可复用 Skill，下次遇到同类任务直接调用，越用越懂你的项目习惯。

**关键能力**
- 持久化记忆：FTS5 检索 + LLM 摘要，跨会话、跨重启保留记忆；记住你的项目架构、命令、偏好，不用每次重复交代上下文。内置 Honcho 用户建模，持续理解你的风格。
- 自动生成技能：完成复杂任务后自动把流程封装成可复用 skill，遵循`agentskills.io`标准，支持后续复用、修改、分享。
- 多平台统一网关： 一套 Agent，多入口：国内版本额外支持** 推推/ 飞书 / 钉钉 / 企业微信**。同一个记忆库，在任意平台继续任务。
- 工具集： 网页浏览、浏览器自动化、图像生成、TTS、Python 脚本执行、定时任务（自然语言设置定时简报、巡检）。
- 模型无关：可以接入任意 LLM，正好适配你之前的 `new-api` 模型网关，接入 OpenAI/Claude/Ollama 本地模型都行。

* [官方网站](https://hermes-agent.nousresearch.com/docs)
